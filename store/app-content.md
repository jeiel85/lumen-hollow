## 타겟층 및 콘텐츠

- 타겟 연령: **13~15세, 16~17세, 18세 이상** (13세 미만을 고르면 가족 정책 요건이 붙는다)
- 아동에게 어필하는가: 아니요 — 어두운 생존·상실 이야기이고 아동용으로 만들지 않았다

## 데이터 보안

| 질문 | 답 |
|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하나요 | 예 |
| 전송 중 데이터가 모두 암호화되나요 | 예 (HTTPS만 쓴다) |
| 계정 만들기 방식 | 앱에서 계정을 만들 수 없음 |
| 데이터 삭제를 요청할 방법을 제공하나요 | 예 — 앱 안 '내 온라인 기록 지우기', 이메일 jeiel85@gmail.com |

수집하는 데이터 유형(모두 **공유하지 않음**, **처리 후 바로 지우는 일시 처리 아님**, **사용자가 선택 가능** — 온라인 보급품을 끄면 보내지 않는다):

| 유형 | 무엇 | 목적 |
|---|---|---|
| 기기 또는 기타 ID | 기기에서 만든 무작위 플레이어 ID(서버엔 해시만), 날마다 바뀌는 비밀값으로 만든 IP의 HMAC(2일) | 앱 기능, 사기 방지·보안·규정 준수 |
| 앱 활동 › 앱 상호작용 | 보급품 사용·고마워요 기록, 접속한 날, 이야기 장면·장 진행 횟수(이 집계는 ID 없이 날짜별 합계만) | 앱 기능, 분석 |
| 앱 활동 › 기타 사용자 제작 콘텐츠 | 남긴 보급품(마을 안 자리 번호, 종류, 정해진 문구 중 하나) | 앱 기능 |

수집하지 않음: 위치, 개인 정보(이름·이메일·주소 등), 금융 정보, 건강, 메시지, 사진·동영상, 오디오, 파일·문서, 캘린더, 연락처, 웹 브라우징, 앱 정보·성능(오류 로그 등), 기기의 다른 앱.

확인할 것: 다른 플레이어에게 보급품을 보여 주는 것은 Play 정의의 '공유(제3자에게 전송)'가 아니라고 보고 '공유 안 함'으로 답했다. #51에서 Google Play 결제를 넣으면 '금융 정보 › 구매 내역' 신고가 필요한지 그때 다시 본다.
