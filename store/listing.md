Play Console → 성장 → 스토어 등록정보 → 기본 스토어 등록정보에 그대로 붙여 넣는다. 영어는 #60(영어 지원)에서 더한다.

## 앱 이름 (30자 이내)

```
Lumen Hollow: 빛으로 버티는 밤
```

## 간단한 설명 (80자 이내)

```
정전된 읍내에 다시 불을 켜고, 손전등 하나로 그림자의 밤을 버티는 생존 이야기
```

## 자세한 설명 (4000자 이내)

> 마지막 문단의 '2~4장 한 번 구매' 문장은 앱 안 결제(#51)가 들어간 버전을 프로덕션에 낼 때 그대로 맞는다. 비공개 테스트 동안 앱은 2~4장이 그냥 열려 있다.

```
그날 밤, 세상의 불이 꺼졌다.

비 오는 정전된 읍내. 낮에는 골목을 뒤져 퓨즈와 배터리를 모으고, 밤에는 손전등과 가로등 불빛에 기대 어둠 속 '그늘이'를 버틴다. 꺼진 배전함에 하나씩 퓨즈를 끼워 동네에 다시 불을 밝히면, 할머니의 무전이 그날 밤의 진실을 조금씩 들려준다.

■ 빛이 곧 생존
그늘이는 빛을 싫어한다. 켜진 가로등 안으로는 들어오지 못하지만, 가장자리에 몰려 버티면 과부하로 차단기가 내려간다. 손전등으로 오래 비추면 흩어져 잠든 주인에게 돌아가고, 깨어난 사람이 숨은 퓨즈 자리에 촛불을 켜 준다.

■ 오늘 밤 어디에 불을 켤까
변전소 출력은 한정돼 있다. 배전반에서 오늘 밤 불을 켤 동네를 골라야 한다. 내일 뒤질 쪽, 밤에 옮겨 다닐 피난처를 생각해서.

■ 한국 읍내의 밤
전봇대와 늘어진 전선, 한글 간판, 함석지붕과 옥상 물탱크, 물 댄 논. 배전함을 고치면 전선을 따라 불빛이 번져 나가고 동네 간판이 켜진다.

■ 낡은 1톤 트럭
연료가 남은 동안 달릴 수 있고, 전조등이 그늘이를 태운다. 세워 두고 짐칸 작업등을 켜면 트럭 둘레가 잠시 안전해진다.

■ 돌아갈 자리 — 네 장의 이야기
등대지기 할머니의 무전, 마을에 남은 생존자들의 기록, 강 건너 구호소와 옛 학교. 흩어진 가족이 서로를 알아보기까지의 이야기를 장면 그림과 함께 따라간다.

■ 그 밖에
· 계정 없음, 광고 없음
· 한 번 받으면 인터넷 없이도 플레이(온라인 보급품만 연결 필요)
· 다른 생존자가 남긴 보급품을 주고받는 비동기 온라인(설정에서 끌 수 있음)
· 세로·가로 화면, 왼손 모드, 화질 설정
· 진행은 자동 저장, 기록 파일로 다른 기기에 옮기기

1장 '돌아갈 자리'는 무료로 끝까지 할 수 있고, 2~4장은 앱 안에서 한 번 구매로 이어진다.
```
