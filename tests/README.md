# 시험

## Node 시험 (`tests/node/`)

브라우저 없이 게임 모듈(`src/`)을 불러와 돌린다. three.js는 `vendor/` 사본을 쓰고 canvas·localStorage는 흉내만 낸다(`env.mjs`). PR마다 `.github/workflows/game-test.yml`이 돌린다.

```bash
node --test --disable-warning=ExperimentalWarning "tests/node/*.test.mjs"
```

`playtime.mjs`는 시험이 아니라 계산 도구다: 2~4장 보강(#58)과 장마다 12장면 보강(v0.25.0)으로 늘어난 플레이 시간을 모형(장면 글자 수·걷는 거리·밤 길이)으로 어림한다. 헤매기·실패는 넣지 않은 하한이라 실측은 비공개 테스트에서 한다(`node tests/node/playtime.mjs`).

기록 자리나 옷가지를 **일부러** 바꿨을 때만 기준값을 다시 뽑는다. 옷가지 id는 더해지기만 한다(빠지면 시험이 실패한다).

```bash
node --disable-warning=ExperimentalWarning tests/node/gen-fixtures.mjs
```

## 브라우저 시험 (`tests/e2e/`)

헤드리스 Chrome을 CDP로 조종해 `?debug`의 `window.lumen`으로 실제 게임을 진행한다. 저장소 폴더를 정적 서버로 띄우고 돌린다(Chrome 위치는 환경 변수 `CHROME`, 없으면 운영체제 기본 위치).

```bash
python -m http.server 8000
```

```bash
node tests/e2e/walk.mjs
```

**영어로 돌리기**: `E2E_LANG=en`을 주면 기기 언어를 영어로 두고 주소에 `?lang=en`을 붙여, 페이지가 열린 순간부터 화면에 나타난 한글(글자·aria-label·title·alt)을 모아 끝에 `HANGUL n`으로 알린다. 한국어 문구를 확인하는 항목은 영어에서 NG가 나는 것이 맞으니 이 모드에서는 HANGUL 줄만 본다. `chapter1.mjs`(1장 끝까지)·`chapters.mjs`(2~4장 끝까지)를 이렇게 돌려 0이어야 한다.

```bash
E2E_LANG=en node tests/e2e/chapters.mjs
```

2~4장에 들어가는 시험(`chapters`·`chapter1`·`resume`·`walk`·`minimap`·`online`·`robust`·`layout`)은 주소에 `?app`을 붙여 앱처럼 연다(`cdp.mjs`의 `fullGame`, 웹판은 1장 데모라서). 인자는 `[url] [폭 높이]`이고, 스크린샷은 `tests/e2e/shots/`(git 제외)에 남는다. 실패가 있으면 종료 코드 1. GitHub Actions의 **Game tests → Run workflow**에서 `e2e`를 켜면 소프트웨어 GL로 같은 시험을 돌린다.

`?debug`에서는 저사양 화질 자동 낮춤이 꺼져 있다(`lumen.step()`이 메인 스레드를 붙잡으면 느린 기기로 보이기 때문). 시험에서는 `lumen.autoQ.off = false`로 켠다.

`lumen.step(초, 간격)`은 기본 0.05초 간격이다. 걷기·충돌처럼 프레임 간격에 따라 결과가 달라지는 것은 `1/60`을 준다(50ms 간격에서는 한 걸음이 0.26m라 좁은 틈을 우연히 넘는다).
