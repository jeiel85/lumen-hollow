# 이야기 설정 《돌아갈 자리》 (스포일러 있음)

게임 속 대사·기록의 원문은 [src/script.js](../src/script.js)에 있고, 여기는 설정과 진행 구조를 한눈에 보기 위한 요약입니다. 대본을 고칠 때 이 문서도 같이 맞춥니다. 글과 설정은 콘텐츠(CC BY 4.0, [LICENSE-CONTENT.md](../LICENSE-CONTENT.md))입니다. 이야기를 다른 작가(사람·AI)에게 넘길 때 쓴 자료는 [story-rewrite-brief.md](story-rewrite-brief.md)입니다.

분위기는 아포칼립스 생존물을 따릅니다. 세상 전체가 무너진 뒤의 고요, 끊긴 재난 방송, 생존자가 문에 써 붙인 규칙, 가족을 향한 먼 길. 특정 작품의 설정·인물·장치는 가져오지 않습니다.

## 네 장

| 장 | 플레이어가 하는 일 | 장이 끝났을 때 달라진 것 |
|---|---|---|
| 1. 돌아갈 자리 | 마을 배전함 여덟 곳을 마음대로의 순서로 고쳐 등대에 전기를 보낸다(생존 판). | 손전등으로 흩어 보낸 것이 사람들의 그림자였음을 안다. 강 건너에서 첫 응답이 온다. |
| 2. 인계 | 나룻배로 섬에 건너가 할머니를 만나고, 다음 등대지기에게 첫 불을 넘긴다. | 스무 날째 무전을 붙든 사람이 자리를 비울 수 있다. |
| 3. 빈 들것 | 강 건너 구호소의 이송 명부와 소지품 봉투를 맞춰 엄마의 행방을 찾는다. | 엄마가 아직 도시에 있다는 믿음이 뒤집힌다. 엄마도 오고 있었다. |
| 4. 점호 | 별관에 예비등 둘을 잇고, 마지막 밤 두 환자의 그림자를 돌려보낸다. | 흩어졌던 세 식구가 서로를 알아본다. 주인공이 직접 첫 아침 방송을 한다. |

## 세 가지 질문

| 질문 | 답 |
|---|---|
| 세상은 왜 갑자기 바뀌었나 | 호수 아래 고인 밤을 누르던 섬 등대 '첫 불'을 의회의 결정으로 소등하자, 어둠이 옛 선로와 송전망을 따라 번져 마을과 도시가 거의 동시에 정전됐다. 스위치를 내린 사람은 등대지기 윤(할머니)이다. 재난 방송은 사흘 동안 이어지다 넷째 날 끊겼다. |
| 왜 빛으로 어둠을 물리쳐야 하나 | 완전한 어둠에서 떨어진 그림자가 밤에 그늘이가 되어 산 사람에게 몰려든다. 빛은 접근을 막고, 손전등을 오래 비추면 그림자가 주인에게 돌아가 주인이 깨어날 수 있다. 창의 불은 귀환의 표현이며 모든 집의 생존을 보증하지 않는다. |
| 궁극적인 목적은 | 1장은 아홉 구역을 이어 첫 불을 다시 켜는 것. 그 뒤로는 엄마를 찾아 돌아갈 자리를 되찾는 것, 그리고 한 사람이 혼자 지던 당직을 여럿이 나누는 것. |

1926년은 마을의 건립 연도가 아니라 열두 가구가 첫 겨울의 재난을 겪고 불과 선로를 지킨 해다. 주인공이 그림자를 잃지 않은 것은 엄마가 쥐여 준 손전등 때문일 수 있다는 할머니의 추정일 뿐, 특별한 혈통이나 확정된 법칙이 아니다. 판이 되풀이되는 것은 게임 관례로 두고 세계관 설정(시간 되감기 등)으로 설명하지 않는다.

## 등장

- **나**: 어린 시절 이 골짜기에 살다 엄마와 도시로 이사했다. 이름·성별은 정하지 않는다. 할머니에게 짧은 해요체.
- **할머니(등대지기 윤)**: 섬에서 등잔과 배터리 무전기로 버텼다. 엄지에 반창고를 세 겹 감을 만큼 무전을 눌렀다. 해라체.
- **엄마**: 할머니의 딸. 그날 밤 아이 손에 손전등을 쥐여 주고 잠들었다. 이송 명부의 17번.
- **오정석**: 대피소 당번. 문밖의 딸 목소리에 문을 열지 못했고, 날이 밝자 찾으러 나가 식당 뒷문 등 밑에서 딸을 찾았다. 4장에서 낯선 환자 곁을 지킨다.
- **도하**: 오정석의 딸. 시험 소등 때 그림자가 늦게 움직이는 걸 먼저 본 아이.
- **식당 주인**: 손님들을 뒷문으로 내보냈다. 2장에서 두 번째 등대지기가 된다(배멀미가 심하다).
- **약사 한서윤**: 잠든 사람 열둘을 돌보다 강 건너 구호소까지 데려왔다. 사실과 추정을 나누는 기록체.
- **낯선 목소리**: 1장 끝의 강 건너 대피소, 4장 끝의 첫 제보자("파란 운동화, 왼쪽 끈만 흰색").

## 진행 구조

**1장**(마을 생존 판): 장면은 첫 판 시작·첫 해질녘·첫 새벽과 고친 구역 수(은신처 포함 2~9)에 묶여 있어 어떤 순서로 고쳐도 대사가 맞는다. 장면이 기록을 열고, 열린 기록은 푸른 빛기둥과 화면 밖 푸른 화살표가 가리킨다.

| 계기 | 장면 | 여는 기록 |
|---|---|---|
| 첫 판 시작 | 남겨 둔 불 | 은신처 관리 일지 |
| 첫 해질녘 · 첫 새벽 | 빛의 가장자리 · 대답 없는 아침 | |
| 2구역 | 첫 번째 수리 | 등대 소등식 안내 |
| 3구역 | 그림자가 떠난 자리 | 식당 메뉴판 뒷면, 약국 야간 기록 |
| 4구역 | 돌아갈 자리 — 그늘이의 정체 | 도하의 일기장 |
| 5구역 | 남겨진 약속 — 1926년 | 광장 동상 명판, 급수탑(장면 「건너편의 불」) |
| 6구역 | 내 손으로 — 할머니의 고백 | 부치지 못한 편지 |
| 7구역 | 끊어 둔 길 — 남겨 둔 접속기 | 전력소 작업 지시서 #1031 |
| 8구역 | 하나를 남기고 | |
| 9구역(승리) | 돌아갈 자리 — 첫 불, 강 건너의 응답 | |

**2~4장**([src/chapters.js](../src/chapters.js)): 1장 엔딩을 본 뒤 처음 화면의 장 단추(또는 1장 승리 화면의 '다음 장')로 들어간다. 지금 할 일이 화면 위 '목표'에 뜨고 푸른 화살표가 그곳을 가리킨다. 순서가 자유로운 곳(2장 두 물건, 3장 두 기록, 4장 예비등 둘)은 어느 쪽을 먼저 해도 다음 장면이 한 번만 열린다.

| 장 | 차례 | 장면 · 기록 |
|---|---|---|
| 2 | 마을 선착장에서 나룻배에 오른다 → 섬 부두에 닿는다 | 나루에서 → 첫 대면(인계부·예비 송수신기가 열린다) |
| 2 | 당직실 인계부와 부두 보관함을 확인한다(순서 자유). 해가 지면 돌계단 고정등 아래가 안전하다 | 인계부, 예비 송수신기 종이띠 |
| 2 | 부두에서 다음 당직자를 부른다 | 대타 → 두 그릇. 나룻배로 섬을 떠나면 3장 |
| 3 | 강 건너 마을 나루에서 둑길을 따라 구호소로 | 열두 번째 칸(명부·봉투가 열린다) |
| 3 | 둑길 창고에서 명부와 봉투를 읽는다(순서 자유). 두 번째를 읽으면 17번을 나란히 보고 사진을 뒤집는다 | 이송 명부, 17번 소지품 봉투 → 엄마의 열쇠 → 문 밖의 아이(귀로의 무전) |
| 3 | 약사에게 반납하고 별관으로 | 약사의 인계 쪽지 → 보호자 자리. 이어서 4장 |
| 4 | 교실 문 앞과 운동장 당직실의 예비등을 잇는다(순서 자유) | 두 사람(점호판이 열린다), 당직실 점호판 |
| 4 | 계단에서 밤을 기다린다 → 문가 쪽 골대를 돌아오는 그림자를 비춘다 | 문가 |
| 4 | 약사에게 물을 받고 다시 비춘다 → 운동장 끝에서 오는 그림자 | 창가 |
| 4 | 교실로 들어간다 → 아침, 방송대에서 송신 | 세 사람 → 첫 아침 방송 → 끝 화면 《돌아갈 자리》 |

4장 목표 그림자는 생김새가 다른 그늘이와 같고, 누구의 그림자였는지는 빛이 들어간 창(문가·창가)과 교실 무전으로만 알린다. 2장만 시간이 흘러 밤이 오고, 3장은 낮, 4장은 이야기가 정한 때(오후 → 그날 밤 → 이튿날 아침)로 넘어간다.

## 풍경

- 호수와 등대섬은 마을 북서쪽 숲 너머(화면 위쪽)에 있다. 1장에서는 급수탑 장면과 엔딩에서만 보이고, 2장에서 마을 선착장 빈터와 섬(등대, 당직실과 처마 밑 밥상, 돌계단과 고정등, 부두와 보관함)을 걷는다.
- 강 건너 옛 학교는 마을·호수와 겹치지 않는 동쪽 먼 곳에 따로 지었다: 나루, 둑길과 물에 잠긴 옛길, 둑길 창고, 본관과 구호소 천막(신발 열한 켤레), 구령대(방송대), 운동장과 골대 둘, 지붕을 걷어 안이 보이는 별관 동쪽 교실, 운동장 당직실. 강 건너편에는 흩어진 그림자가 돌아가는 마을 집들이 있다.
