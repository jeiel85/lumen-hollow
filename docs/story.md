# 이야기 설정 (스포일러 있음)

게임 속 무전·기록의 원문은 [src/script.js](../src/script.js)에 있고, 여기는 설정과 진행 구조를 한눈에 보기 위한 요약입니다. 대본을 고칠 때 이 문서도 같이 맞춥니다. 글과 설정은 콘텐츠(CC BY 4.0, [LICENSE-CONTENT.md](../LICENSE-CONTENT.md))입니다.

분위기는 아포칼립스 생존물을 따릅니다. 세상 전체가 무너진 뒤의 고요, 끊긴 재난 방송, 생존자가 문에 써 붙인 규칙, 가족을 향한 먼 길. 특정 작품의 설정·인물·장치는 가져오지 않습니다.

## 세 가지 질문

| 질문 | 답 |
|---|---|
| 세상은 왜 갑자기 바뀌었나 | 루멘 할로("빛이 고인 골짜기")의 밤은 물처럼 고인다. 백 년 전 정착민들이 호수 섬에 세운 등대, **첫 불**이 그 어둠을 눌러 왔다. 스무 날 전 그믐밤, 마을 의회가 운영비로 가로등 백 개를 달겠다며 등대를 껐다(소등식). 자정에 호수 밑바닥의 어둠이 일어나 전깃줄을 타고 마을로, 골짜기 밖 송전망을 따라 도시로 번졌고 **세상의 불이 한꺼번에 나갔다**. 재난 방송은 사흘 만에 끊겼다. |
| 왜 빛으로 어둠을 물리쳐야 하나 | 완전한 어둠에서는 그림자가 붙어 있을 데가 없어 사람에게서 떨어져 나간다. 그림자를 잃은 사람은 깨지 않는 잠에 빠진다. **그늘이는 괴물이 아니라 잠든 사람들의 그림자**이고, 아직 그림자가 붙어 있는 주인공에게 몰려든다. 빛을 오래 받은 그림자는 다시 드리울 자리를 찾아 **주인에게 돌아간다**(손전등으로 흩어지는 것). 불 켜진 동네의 창문이 밝아지는 건 사람들이 깨어나는 것이다. |
| 궁극적인 목적은 | 등대 램프는 마을에서 끌어온 1926년 옛 선로로 켜지고, **마을 아홉 구역에 모두 전기가 들어와야** 선로 전압이 찬다. 첫 불을 다시 켜면 골짜기가 잠들고, 어둠이 번진 길을 따라 불이 다시 번져 나간다. 엔딩에서 침묵하던 무전기에 다른 대피소의 목소리가 들어오고, 할머니는 "배를 타고 건너와라, 그다음엔 네 엄마한테 가자"고 한다(다음 장의 고리). |

## 등장

- **나**: 도시에 살던 생존자. 그날 밤 엄마가 잠들어 깨어나지 않았다. 라디오에서 반복되던 할머니의 무전("누구든 들리면 루멘 할로로 오너라")을 따라 스무 날을 걸어 골짜기에 닿는다. 은신처(마을 비상 대피소) 비상함에서 퓨즈 한 개를 찾는다.
- **할머니(등대지기 윤)**: 호수 섬 등대에서 등잔 하나로 버티며 무전으로 이끈다. 등대에서는 골짜기가 내려다보여서 구역에 불이 들어올 때마다 무전이 온다. 소등식 날 스위치를 내린 건 자기 손이었다고, "세상을 끈 건 나다"라고 고백한다.
- 기록 속 생존자들: 문에 규칙을 써 붙이고 딸을 찾으러 나간 대피소 당번 오정석, 라이터 하나로 버틴 다이너 주인, 잠든 사람 열두 명을 돌본 약사 한서윤, 어른들보다 먼저 알아챈 아이 도하, 1926년의 열두 가구.
- **낯선 목소리**: 엔딩에서 처음 들리는 다른 대피소의 생존자. 세상에 아직 사람이 남아 있다는 신호.

## 진행 구조

장면을 보면 기록이 열리고, 열린 기록 위에는 푸른 빛기둥과 화면 밖 푸른 화살표가 뜬다. 본 장면과 주운 기록은 이 브라우저에 남아 다음 판에도 이어진다(이미 본 장면은 다시 나오지 않고, 수첩에서 다시 볼 수 있다).

| 계기 | 무전 장면 | 여는 기록 |
|---|---|---|
| 첫 판 시작 | 스무 날째 — 할머니의 반복 무전을 따라 도착 | 은신처 관리 일지(대피소 규칙) |
| 첫 해질녘 · 첫 새벽 | 해질녘 / 첫 아침 — "지금 말하면 손전등을 못 비출 게다" | |
| 불 2구역 | 첫 불 — 소등식 | 등대 소등식 안내(남쪽 광장 게시판) |
| 불 3구역 | 그림자 — 어둠이 전깃줄을 타고 세상으로 | 다이너 메뉴판 뒷면, 약국 야간 기록 |
| 불 4구역 | 돌아가는 그림자 — 그늘이의 정체 | 도하의 일기장(동북 주택가) |
| 불 5구역 | 골짜기의 첫 불 — 1926년 | 광장 동상 명판, 급수탑(호수와 등대를 보는 장면) |
| 불 6구역 | 고백 — 스위치를 내린 사람 | 부치지 못한 편지(동남 주택가 우편함) |
| 불 7구역 | 옛 선로 | 전력소 작업 지시서(헛간 들판) |
| 불 8구역 | 마지막 하나 | |
| 불 9구역(승리) | 다시 켜진 첫 불 — 등대 점등, 다른 생존자의 무전, 엔딩 | |

## 풍경

호수와 등대섬, 선착장과 묶인 나룻배는 마을 북서쪽 숲 너머(화면 위쪽)에 있다. 걸어서는 갈 수 없고 급수탑 장면과 엔딩에서만 보인다. 다음 장에서 배로 호수를 건너는 이야기를 붙일 자리다.
